# Actividad Integradora 3

Sistema de registro y consulta de productos desarrollado con PHP, MySQL y patrón MVC.

## Tecnologías

- PHP
- MySQL
- HTML/CSS
- JavaScript

## Instalación

1. Clonar el repositorio
2. Importar `script.sql` en phpMyAdmin
3. Copiar la carpeta a `C:\xampp\htdocs\`
4. Abrir `http://localhost/actividad-integradora-3/`

## Estructura

```
actividad-integradora-3/
├── config/          # Conexión a MySQL
├── controllers/     # Lógica de negocio
├── models/          # Modelo de datos
├── views/           # Vistas HTML
├── css/             # Estilos
├── js/              # JavaScript
├── index.php        # Punto de entrada
└── script.sql       # Base de datos
```

## Funcionalidades

- Registrar productos
- Consultar productos registrados
- Validaciones de formulario
- Interfaz responsiva
